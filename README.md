# Перенос сайта Wordmaster

Публикация сайта перенесена на адрес:

**https://alsibir.github.io/aps-expert/**

Старый адрес `https://alsibir.github.io/wordmaster/` сохранён для автоматической переадресации посетителей.

В файлах `index.html` и `404.html` настроена немедленная переадресация через `window.location.replace` и резервный `meta refresh` для браузеров без JavaScript. Канонический адрес указывает на новый сайт; старый не должен индексироваться. Поскольку GitHub Pages предоставляет статический хостинг, HTTP-редирект 301 из этих файлов недоступен.
